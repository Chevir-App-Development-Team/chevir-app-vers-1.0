# Çoxdillilik (i18n)

Hazırda yalnız **ana səhifə** iki dildədir: AZ (`/`) və EN (`/en/`). `/tercume/`
və `/nsosyal/` hələ yalnız AZ-dır, öz koduna bu sistem qoşulmayıb.

## Struktur

```
src/i18n/
  pages.config.js   - hansı səhifə hansı JSON fayllarını işlədir, hansı dilə aiddir
  html-plugin.js    - build/dev zamanı {{key}} yer tutucularını əvəz edən Vite plugin-i
  az/common.json    - paylaşılan mətnlər (naviqasiya, brend adı) - Azərbaycan dili
  az/home.json      - ana səhifəyə məxsus mətnlər - Azərbaycan dili
  en/common.json    - eyni açarlar, ingilis dili
  en/home.json      - eyni açarlar, ingilis dili
```

Hər JSON faylı **flat** (dot-notation) açarlardır, məsələn:

```json
{
  "hero.title.line1": "Jest dilini",
  "pipeline.step.0.title": "Görüntü və izləmə"
}
```

Koddan çağırılanda açarın əvvəlinə fayl adı (namespace) əlavə olunur:
`t('home.hero.title.line1')`, `t('common.nav.cta')`.

## Mətn necə dəyişdirilir/əlavə olunur

1. Həm `az/<namespace>.json`, həm `en/<namespace>.json`-a eyni açarı əlavə et
   (ingiliscə dəyəri hələ bilmirsənsə, müvəqqəti AZ mətni qoy - sonra üzərinə yaz).
2. Koddakı müvafiq `src/sections/*.js` faylında `t('<namespace>.<açar>')`
   çağırışı ilə işlət (fayl başında `import { t } from '../lib/i18n.js'`).
3. `<head>`-dəki başlıq/meta mətnləri üçün (yalnız `index.html`/`en/index.html`)
   `{{namespace.açar}}` yer tutucusu yaz - bunu build-plugin dəyişdirir, JS-ə
   toxunmaq lazım deyil.

## Yeni səhifəyə dil necə qoşulur

Nümunə: `/tercume/`-ə EN əlavə etmək istəsən:

1. `src/i18n/az/tercume.json` və `src/i18n/en/tercume.json` yarat (açarlar
   `"xxx.yyy"` formatında, `home.json` kimi).
2. `src/i18n/pages.config.js`-də:
   - `NAMESPACES_BY_PAGE.tercume = ['common', 'tercume']`
   - `HTML_ENTRIES`-ə iki sətir: `'tercume/index.html'` (artıq var) və
     `'en/tercume/index.html'` (yeni).
3. `en/tercume/index.html` faylını yarat (mövcud `tercume/index.html`-in
   struktur surəti, `{{tercume.meta.title}}` kimi yer tutucularla, `lang="en"`).
4. `vite.config.js`-in `rollupOptions.input`-una yeni giriş nöqtəsini əlavə et.
5. Tərcümə sisteminin öz JS-ində (`src/tercume/main.js`) mətnləri `t()`-ə köçür.
6. `navbar.js`-dəki `PAGE_EN_PATH`-a `tercume: 'en/tercume/'` əlavə et - AZ|EN
   keçidi avtomatik düzgün yola yönləndirəcək.

Hamburger menyusu lazımdırsa: `navbar.js`-dəki `MENU_ENABLED_PAGES`-ə səhifə
adını əlavə et - CSS (`navbar.css`) `[data-nav-menu]` atributuna bağlı olduğu
üçün başqa heç nəyə toxunmaq lazım deyil.

## Davranış qaydaları

- `t(key)` tapılmayan açarda konsola xəbərdarlıq yazır və açarın özünü
  qaytarır (sükutla boş mətn göstərmir - əskik tərcümə dərhal görünür).
- Dil `document.documentElement.lang`-dan oxunur - hər HTML faylı öz dilini
  statik olaraq elan edir (`<html lang="az">` / `<html lang="en">`).
- Splash/naviqasiya/scroll animasiyaları dildən asılı deyil - hər iki dil
  eyni JS bundle-ını yükləyir, yalnız mətn mənbəyi fərqlidir.
